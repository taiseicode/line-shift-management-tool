# LINEシフト管理ツール 利用説明書

このフォルダは、利用説明書を保管する場所です。店舗管理者・従業員へ渡すPDFを作るときに使います。

## ファイル構成

```text
docs/manual/
  index.html
  style.css
  images/
```

## 説明書を開く方法

1. `index.html` をダブルクリックします。
2. ブラウザで説明書が開きます。
3. 画面例と操作手順を確認します。

## PDFにする方法

1. `index.html` をブラウザで開きます。
2. `Ctrl + P` を押します。
3. 送信先を「PDFに保存」にします。
4. 用紙サイズを `A4` にします。
5. 余白は「標準」または「狭い」を選びます。
6. 背景を印刷する設定がある場合はONにします。
7. PDFとして保存します。

## 画像を更新する方法

`images/` の中にある同じ名前の画像を置き換えると、説明書の画像も更新されます。

主な画像名:

- `admin_home.png`
- `admin_sidebar.png`
- `admin_users.png`
- `admin_deadline.png`

## 画像を撮るときのおすすめ

- ブラウザ倍率は100%
- PC画面で撮影
- 画面幅は広めにする
- 必要な部分だけを切り抜く
- 文字が読める大きさで保存
- PNG形式がおすすめ
- 個人情報が見える場合は隠す

## 更新時の確認

- 画像と説明文が合っているか確認します。
- 「保存する」「表示する」「Excel出力」など、実際に押すボタン名が画面と合っているか確認します。
- PDF保存前に印刷プレビューで崩れていないか確認します。
